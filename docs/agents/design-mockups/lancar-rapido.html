Revisão de proposta · App de campo  —  P0+P1 · Lançar reorganizado + glossário

Hoje: a grade do Lançar tem blocos do mesmo tamanho pra tudo — inclusive "Baixar animal" e "Excluir lançamento" (irreversíveis) ao lado de "Produção" (rotina diária). No Menu, siglas como IATF/PEV/BST aparecem sem tradução nenhuma.

Proposta: as 3 ações mais frequentes ficam grandes no topo; o resto vira uma linha secundária menor; as duas ações irreversíveis ganham uma "zona de risco" com borda tracejada vermelha, visualmente separada do resto. No Menu, cada sigla ganha uma linha de tradução simples embaixo.
